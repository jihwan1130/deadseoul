# DEAD:SEOUL — MVP 프로토타입 v0.1

좀비 바이러스가 퍼진 대한민국을 배경으로 한 **2D 탑다운 생존 게임**.
본 저장소는 **EPISODE 1「막차」(2호선 5호차 내부)** 한 챕터만을 구현한 수직 슬라이스입니다.

> 기획 원칙: **"방 하나만 만들더라도 디테일은 챙긴다."**
> 맵은 전동차 1량(약 28m)뿐이지만, 그 안에서 돌아가야 할 시스템은 전부 돌아갑니다.

---

## 실행 방법

### 1) 바로 열기
`index.html`을 더블클릭하면 됩니다. (ES 모듈이 아닌 클래식 스크립트라 `file://`에서도 동작)

### 2) 로컬 서버 (권장 — 오디오/캐시 거동이 더 안정적)
```bash
npx serve .          # 또는
python -m http.server 8787
```

외부 이미지·사운드 에셋이 **0개**입니다. 스프라이트/타일/아이콘은 전부 캔버스 코드로 그리고,
효과음·환경음은 WebAudio로 합성합니다. (에셋 확보 후 교체할 지점은 각 파일 상단 주석에 명시)

## 구현된 핵심 루프

### 생존 스탯
`체력 / 스태미나 / 허기 / 갈증` 4종 + 상태이상(`출혈 · 연기 흡입 · 각성 · 취기 · 방독면 · 팔 보호대 · 탈진`).
허기·갈증이 0이 되면 체력이 깎이고 최대 스태미나가 줄어듭니다. 물린 상처는 **출혈**로 이어지고, 붕대 없이는 멎지 않습니다.

### 전투
- 무기별 `피해 / 사거리 / 각도 / 쿨다운 / 넉백 / 스태미나 / 내구도 / 소음`
- **치명타 2종**: 눈치채지 못한 적 기습(`무기 치명타 배율`), 등 뒤 타격(`×1.35~`)
- 히트스톱 · 화면 흔들림 · 혈흔 데칼(맵에 영구 누적) · 넉백 · 경직
- 무기는 **부러집니다**. 우산 34회, 소화기 22회.

### 소음 · 감지
좀비는 **시야(원뿔 + 벽 레이캐스트)** 와 **청각** 양쪽으로 반응합니다.
달리기(76px) < 타격(16~70px) < 비상 코크(170px) < 문 개방(180px) 순으로 시끄럽습니다.
밝은 곳에 서 있거나 손전등을 켜면 시야 감지 거리가 늘어납니다.

### 수색 · 크래프팅
좌석 아래 틈, 승객 가방, 시신, 비상용품함, 차량 점검함 — 각각 다른 루트 테이블.
좀비 시체도 수색 가능합니다.

| 레시피 | 재료 | 비고 |
|---|---|---|
| 임시 팔 보호대 | 청테이프 1 + 무가지 2 | 물림 피해 −45% (부산행 오마주) |
| 급조 창 | 손잡이 봉 + 커터칼 + 청테이프 | 리치 2.1타일 |
| 소독 붕대 | 손수건 + 소주 | 회복량 2배 |
| 화염병 | 빈 페트병 + 손수건 + 소주 | **잠김** — "지하에서 불을 지르면 우리도 같이 구워진다" |

### 조명 연출
멀티플라이 라이트 버퍼 + 형광등 깜빡임 + 비상등(적색) + 손전등 부채꼴 + 화재 광원.
연기는 조명 **이후**에 렌더링해 빛에 먹히지 않습니다. 비네트 / 필름 그레인 / 주사선 / 저체력 적색 펄스.

### 세이브
`localStorage` 자동 저장. **체크포인트는 "되살아날 수 있는 지점"이어야 한다**는 원칙으로,
체력 30% 미만·출혈 중·추격당하는 중에는 저장하지 않으며, 복귀 시 체력 32 / 무적 2.5초를 보정합니다.

## EPISODE 1 진행 구조

```
intro      막차 안. 급정차. 안내방송 두절.
  ↓
survey     앞쪽(4호차)으로 이동 → 트리거
  ↓
outbreak   정전 → 비상등 → 4호차 관통문 개방 → 첫 감염자
  ↓        (맨손의 무력함을 체감시키는 구간)
armup      무기 확보 + 감염자 3기 정리 (시차 유입)
  ↓
minseo     차량 끝에 숨어 있던 생존자 접촉
  ↓        └─ 선택지 ─┬─ 의뢰 수락 → 백팩 회수 → 동행 확보
  ↓                   └─ 거절      → 혼자 탈출 (엔딩 분기)
exitwork   비상 코크 수동 개방 (2.4초 홀드 · 큰 소음 → 추가 유입)
  ↓
fire       6호차 화재 → 연기 전선이 좌측으로 전진
  ↓        비상용품함에서 방독면 확보 못 하면 질식
escape     출입문 수동 개방 (3.4초 홀드) → 선로 진출
  ↓
ending     「혼자서 / 둘이서, 지상까지 1.2 km」 + 다음 화 예고
```

**엔딩 분기**: 민서 동행 여부에 따라 제목·본문·결산이 달라집니다.
(멀티버스 엔딩 수집형이 아니라, 선택의 흔적이 남는 방식 — 기획서 방향 그대로)

## 맵 설계 (56 × 15 타일 = 896 × 240 px ≒ 28m × 7.5m)

```
y0       터널 벽
y1       차체 상부 — 창(W) / 출입문(D) / 광고판(A) / 승강구 기둥(#)
y2~y3    상부 좌석 (등받이 + 쿠션, 차량 양단은 노약자·임산부 배려석)
y4~y8    통로 5타일 — 승강구마다 스탠션 폴
y9~y10   하부 좌석
y11      차체 하부 — 2번 출입문이 탈출구
y12~y14  선로 자갈 · 레일 · 대피로 난간 (하부 2번 문으로만 진출)

x0 / x55 관통문 — 좌: 4호차(감염 유입) / 우: 6호차(화재 발원)
승강구   x 6-9, 19-22, 32-35, 45-48 (상·하 각 4개소)
```

한국 전동차 디테일: 노선도, 차량번호 `5-4`, 비상벨, 황색 안전선 + 점자블록,
스테인리스 좌석 구분봉, 천장 손잡이(머리 위 레이어에서 흔들림), 임산부 배려석 분홍 좌석.

### 배치된 설비
| 설비 | 위치 | 기능 |
|---|---|---|
| 비상용품함 | 3번 승강구 상부 기둥 | 방독면 1 + 붕대 2 + 청테이프 1 **확정 지급** |
| 소화기 | 1번 승강구 하부 | 중량 무기 + 분말 분사(3회) |
| 비상 코크 | 2번 승강구 하부 | 출입문 잠금 해제 |
| 비상통화장치 | 4번 승강구 상부 | 차장 교신 (스토리 힌트) |
| 차량 점검함 | 1번 승강구 상부 | 청테이프·커터칼 |
| 승무원 메모 | 우측 관통문 | 대피 경로 정보 |

### 알려진 제약
- 좀비 길찾기는 직선 추적 + 측면 우회 방식(A* 아님). 1량짜리 맵에서는 충분하지만 복잡한 맵에서는 교체 필요.
- 연출 타이밍 일부가 `setTimeout` 기반이라 게임 내 시간과 분리되어 있음. 멀티 스테이지 확장 시 타임라인 시스템으로 통합 권장.
- 효과음이 전부 합성이라 "진짜 한국 지하철" 느낌은 실제 녹음 에셋으로 교체해야 완성됩니다.
